# Changelog

## 0.1.0

- Initial Arkive installer for the original Raspberry Pi Zero W / armhf.
- Final `/srv/arkive` layout and content-only FTP chroot.
- Isolated same-channel Wi-Fi AP with DHCP-only service.
- Lighttpd portal and SQLite FTS5 document search.
- Local-first document indexing with optional Gemini metadata enrichment.
- Automatic Kiwix library reconciliation for uploaded/deleted ZIM files.
